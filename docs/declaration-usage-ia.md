# Déclaration d’usage de l’IA

**Étude de cas PMT (Project Management Tool) – Patrice RAÏ**

## Outil utilisé

Claude Code (Anthropic), assistant d’IA générative et de programmation en ligne de commande.

## Usage

J’ai utilisé un assistant d’IA générative (Claude Code) dans le cadre de cette étude de cas, principalement pour m’accompagner dans le développement, optimiser certaines parties du code, corriger des erreurs et effectuer des vérifications techniques.

L’IA est intervenue en complément de mon travail sur :

- La conception de la base de données et les scripts SQL ;
- Le développement back-end Spring Boot et front-end Angular ;
- La réalisation des tests et la vérification de la couverture de code ;
- La configuration Docker et Docker Compose ;
- La mise en place de la chaîne CI/CD avec GitHub Actions ;
- La rédaction de la documentation technique.

## Ma contribution personnelle

J’ai participé activement à la conception et au développement du projet tout en m’appuyant sur l’assistance de l’IA au fil de sa réalisation.

J’ai également vérifié et adapté les propositions de l’IA afin de m’assurer qu’elles répondaient aux exigences de l’énoncé et à mes choix techniques.
